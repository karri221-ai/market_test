# Market Test
Ядро интернет-магазина. 

## Реализовано
   - Класс Product: название, описание, цена, количество
   - Класс Category: название, описание, список товаров
   - Автоматические счётчики категорий и товаров
   - Тесты на pytest, покрытие 100%
   - Загрузка категорий и товаров из JSON-файла (`load_categories`)
   - приватные атрибуты и add_product, геттер products, класс-метод new_product, геттер и сеттер цены с проверкой.
   - Подтверждение `y/n` при снижении цены
   - Поиск дубликатов в `new_product`: количество суммируется, цена берётся большая
   - Строковое представление `Product` и `Category` (`__str__`)
   - Сложение товаров `a + b` (`__add__`): полная стоимость остатков на складе
   - Итератор `CategoryIterator` для перебора товаров категории в цикле
   - Классы Smartphone и LawnGrass

## Установка и запуск
    poetry install
    poetry run python main.py
    poetry run pytest --cov=src
